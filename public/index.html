    AI機器人

    串接你的 LINE 官方帳號，集中查看新對話。

    先備份 LINE Developers 的原網址，再將此網址填入 Webhook URL，開啟 Use webhook 並按 Verify。然後傳一則新訊息給 OA。

    連接你的 LINE 官方帳號

    在 LINE Developers 的 Basic settings 取得 Channel ID、Channel Secret；Messaging API 分頁可取得 Channel access token（long-lived）。

    Secret 會加密保存於後端；Access Token 僅用於確認 OA 身分，不會保存。綁定前請於 10 分鐘內重新登入。
